# عسلک CRM — برنامهٔ اندروید (APK)

این پروژه یک «پوستهٔ» سبک اندروید برای عسلک CRM است. خودِ CRM و همهٔ اطلاعات روی کامپیوتر فروشگاه می‌مانند (با `run.bat`)؛ این برنامه فقط صفحهٔ CRM را روی گوشی نشان می‌دهد.

## امکانات
- ورود به CRM با همان نام کاربری و رمز؛ ماندن در حالت ورود
- آپلود فایل (اکسل، عکس فیش) از گوشی
- دانلود خروجی‌ها (اکسل و PDF) در پوشهٔ Downloads
- چاپ فاکتور و ذخیره به‌صورت PDF از منوی چاپ اندروید
- دکمهٔ ⚙ پایین-چپ: تغییر آدرس سرور، بارگذاری مجدد، پاک‌کردن حافظهٔ موقت

## ساخت APK با گیت‌هاب (بدون نصب Android Studio)
1. در github.com یک مخزن جدید بسازید (مثلاً `asalac-android`).
2. **همهٔ فایل‌ها و پوشه‌ها را آپلود کنید** (Add file ← Upload files)، **به‌جز پوشهٔ `.github`** (چون نقطه‌دار و پنهان است و گیت‌هاب/ویندوز آن را در آپلود نمی‌گیرد). پوشه‌های `app` و فایل‌های `build.gradle.kts`، `settings.gradle.kts`، `gradle.properties`، `.gitignore` (اختیاری) آپلود شوند. بعد Commit کنید.
2-ب. **ساخت دستی فایل Workflow (۱ دقیقه):** در همان مخزن: Add file ← **Create new file**. در کادر نام فایل دقیقاً این را تایپ کنید (با تایپ `/` پوشه‌ها خودکار ساخته می‌شوند):
   `.github/workflows/build-apk.yml`
   سپس کل محتوای فایل `build-apk.yml` (که کنار همین README در zip هست) را کپی و Paste کنید و **Commit changes** بزنید.
3. تب **Actions** را باز کنید؛ کار «Build APK» خودکار اجرا می‌شود (حدود ۳ تا ۵ دقیقه). اگر اجرا نشد: Build APK ← Run workflow.
4. بعد از سبز شدن، روی همان اجرا کلیک کنید و از بخش **Artifacts** فایل `AsalacCRM-apk` را دانلود کنید (zip است؛ داخلش `AsalacCRM.apk`).
5. (اختیاری) برای لینک مستقیم دانلود: در تب Releases یا با ساختن تگ `v1.0` (`git tag v1.0 && git push --tags`) فایل APK در Releases قرار می‌گیرد.

## نصب روی گوشی
1. فایل `AsalacCRM.apk` را روی گوشی بیاورید و باز کنید.
2. اگر اندروید پرسید، «نصب از این منبع» را برای مرورگر یا مدیر فایل مجاز کنید.
3. اولین اجرا آدرس سرور را بپرسد: آدرس کامپیوتر را بنویسید، مثل `http://192.168.1.10:3000`.

## آدرس کامپیوتر را از کجا بیاورم؟
- روی کامپیوتر `run.bat` را اجرا کنید (خط `LAN=1` باید فعال باشد؛ در نسخهٔ فعلی هست).
- در Command Prompt بنویسید `ipconfig` و مقدار **IPv4 Address** را بردارید (مثل 192.168.1.10).
- گوشی و کامپیوتر باید به **یک وای‌فای** وصل باشند.
- اگر ویندوز پرسید، برای Node.js روی «Allow access» (شبکهٔ خصوصی) بزنید.
- ادرس کامل: `http://IPv4:3000`

## نکته‌ها
- نسخهٔ ساخته‌شده **Debug** است و با کلید آزمایشی امضا می‌شود؛ برای استفادهٔ داخلی و نصب مستقیم مناسب است، نه انتشار در Google Play.
- ارتباط HTTP است و فقط داخل شبکهٔ محلی کار می‌کند؛ از بیرون خانه (اینترنت) کار نمی‌کند.
- اندازهٔ APK کوچک است چون هیچ داده‌ای در آن نیست.
